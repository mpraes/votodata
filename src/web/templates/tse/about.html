Sobre este catálogo

Interface de leitura do schema PostgreSQL dados_tse, alimentado pelo ETL em src/etl/metadados_tse.

Pipeline

  • extract — API CKAN + HTML fallback → JSON local
  • load — upsert no Postgres (no-op por metadata_hash)
  • probe — HEAD na CDN (status_link, tamanho, ETag)
  • enrich-files — download + SHA-256 + colunas CSV (datasets prioritários)

Convenções dos arquivos TSE

Resumo das regras recorrentes nos leia-me.pdf (parse automático ainda não entra neste MVP):

  • Codificação Latin-1
  • Campos entre aspas, separados por ponto e vírgula
  • #NULO = vazio; numéricos equivalentes a -1
  • #NE = informação não existia na época; numéricos -3
  • UF pode incluir BR (nacional), VT (trânsito), ZZ (exterior)

Operação

Subir o app (homelab, bind local):

make web → http://127.0.0.1:8000

Sem autenticação neste MVP — use Tailscale / bind em 127.0.0.1.
